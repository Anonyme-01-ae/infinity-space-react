# Infinity Space Club

Site web React pour présenter le club universitaire Infinity Space de la Faculté des Sciences Ben M'Sik.

## Fonctionnalités

- Présentation du club
- Liste des membres du bureau
- Activités réalisées
- Activités à venir
- Formulaire pour rejoindre le club
- Footer avec contact

## Technologies

- ReactJS
- JavaScript ES6+
- Bootstrap
- CSS

## Lancer le projet

npm install
npm start
